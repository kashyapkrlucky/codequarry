## File conventions

```text
app/
├── layout.tsx          # root layout (required, renders <html> and <body>)
├── page.tsx            # route UI for "/"
├── loading.tsx         # Suspense fallback for the segment
├── error.tsx           # error boundary (client component)
├── not-found.tsx       # UI for notFound()
├── blog/
│   ├── page.tsx        # "/blog"
│   └── [slug]/
│       └── page.tsx    # "/blog/:slug"
├── (marketing)/        # route group — not part of the URL
├── api/health/route.ts # route handler: GET/POST/... functions
└── sitemap.ts          # generated sitemap.xml
```

| File | Purpose |
| --- | --- |
| `layout.tsx` | Shared UI that persists across navigations |
| `template.tsx` | Like layout, but remounts on navigation |
| `route.ts` | HTTP endpoint (cannot coexist with `page.tsx`) |
| `opengraph-image.tsx` | Generated OG image for the segment |
| `[...slug]` / `[[...slug]]` | Catch-all / optional catch-all |

## Pages and dynamic routes

```tsx
// app/blog/[slug]/page.tsx
export async function generateStaticParams() {
  const posts = await getPosts();
  return posts.map((p) => ({ slug: p.slug }));
}

export default async function Post({ params }: PageProps<"/blog/[slug]">) {
  const { slug } = await params;          // params and searchParams are promises
  const post = await getPost(slug);
  if (!post) notFound();
  return <article>{post.title}</article>;
}
```

<Callout type="info">
`PageProps` and `LayoutProps` are globally available, route-aware types generated by `next dev`, `next build`, or `next typegen`.
</Callout>

## Data fetching

Server Components can be `async` and fetch directly — no API layer needed.

```tsx
export default async function Dashboard() {
  const [user, stats] = await Promise.all([getUser(), getStats()]); // parallel
  return <Stats user={user} stats={stats} />;
}
```

Stream slow parts with Suspense so the rest of the page renders immediately:

```tsx
<Suspense fallback={<FeedSkeleton />}>
  <Feed />
</Suspense>
```

## Caching with Cache Components

Enable with `cacheComponents: true` in `next.config.ts`. Data is dynamic by default; opt in to caching with `"use cache"`.

```tsx
import { cacheLife, cacheTag } from "next/cache";

export async function getProducts() {
  "use cache";
  cacheLife("hours");          // seconds | minutes | hours | days | weeks | max
  cacheTag("products");
  return db.product.findMany();
}
```

| Need | API |
| --- | --- |
| Cache a function or component | `"use cache"` |
| Set lifetime | `cacheLife("hours")` |
| Label for invalidation | `cacheTag("products")` |
| Invalidate (stale-while-revalidate) | `revalidateTag("products", "max")` |
| Invalidate immediately from a Server Action | `updateTag("products")` |
| Force request-time rendering | `await connection()` |

<Callout type="warning">
Cached scopes cannot read `cookies()`, `headers()` or `searchParams`. Read them outside and pass the values in as arguments.
</Callout>

## Server Actions

```tsx
// app/todos/actions.ts
"use server";
import { updateTag } from "next/cache";
import { z } from "zod";

const schema = z.object({ title: z.string().min(1).max(200) });

export async function addTodo(formData: FormData) {
  const { title } = schema.parse({ title: formData.get("title") });
  await db.todo.create({ data: { title } });
  updateTag("todos");
}
```

```tsx
<form action={addTodo}>
  <input name="title" required />
  <button type="submit">Add</button>
</form>
```

Server Actions are public HTTP endpoints: always validate input and check authorisation inside them.

## Route handlers

```ts
// app/api/items/route.ts
import type { NextRequest } from "next/server";

export async function GET(request: NextRequest) {
  const q = request.nextUrl.searchParams.get("q") ?? "";
  return Response.json(await searchItems(q));
}

export async function POST(request: Request) {
  const body = await request.json();
  return Response.json(await createItem(body), { status: 201 });
}
```

## Metadata

```tsx
export const metadata: Metadata = {
  title: { default: "Acme", template: "%s · Acme" },
  description: "…",
  metadataBase: new URL("https://acme.com"),
};

export async function generateMetadata({ params }: PageProps<"/blog/[slug]">): Promise<Metadata> {
  const post = await getPost((await params).slug);
  return { title: post.title, alternates: { canonical: `/blog/${post.slug}` } };
}
```

## Proxy (formerly middleware)

```ts
// proxy.ts at the project root
import { NextResponse, type NextRequest } from "next/server";

export function proxy(request: NextRequest) {
  if (!request.cookies.has("session")) {
    return NextResponse.redirect(new URL("/login", request.url));
  }
}

export const config = { matcher: ["/dashboard/:path*"] };
```

## Environment variables

| Variable | Available in |
| --- | --- |
| `DATABASE_URL` | Server only |
| `NEXT_PUBLIC_SITE_URL` | Server and browser (inlined at build time) |

Add `import "server-only"` to modules that must never be bundled for the client.

## Common mistakes

- **Adding `"use client"` to whole pages** — push it down to the interactive leaf.
- **Fetching in a Client Component** what a Server Component could fetch directly.
- **Sequential awaits** for independent data — use `Promise.all`.
- **Forgetting `await params`** — `params` is a promise in current Next.js.
